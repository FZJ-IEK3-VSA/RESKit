# Solar Energy

RESKit provides the functionality needed to simulate photovoltaic plants.

1. The [first example](../examples/4_solar/4_1_solar_workflows_overview.ipynb) provides an overview of the available predefined workflows for photovoltaic (PV) plants in RESKit.
2. The [second example](../examples/4_solar/4_2_check_available_pv_modules.ipynb) demonstrates how to check for available photvolatic modules to simulate and select available PV modules for a simulation.
3. The [third example](../examples/4_solar/4_3_solar_automated_simulation_workflow.ipynb) shows how to simulate single and multiple PV plants, with and without tracking.
